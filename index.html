Research Flow: Maze RNN Multi-Turn V1 (Auto-GS)

53 research events · Click any event to see full context
Goal Set #1
The main research goal is defined: investigate if an RNN can learn a generalizable world model for maze navigation from egocentric observations.
Milestone Set #2
An initial milestone is set: build a maze environment and implement a baseline LSTM/GRU agent with PPO.
Work #3
Implementation of the entire baseline experiment begins, including environment, agent, and training loop.
Experiment #4
A sanity check experiment is run to verify the codebase.
Observation #5
The sanity check reveals a discrepancy: success during stochastic training but 0% during deterministic evaluation.
Hypothesis #6
The discrepancy is hypothesized to be due to the agent relying on random exploration rather than learning a robust policy.
Experiment #7
A full-scale baseline training experiment is conducted.
Finding #8
Initial (but flawed) results suggest the agent generalizes surprisingly well to 2x size mazes.
Observation #9
An anomaly is observed: performance on 15x15 mazes is worse than on 21x21 mazes.
Pivot #10
The evaluation methodology is identified as flawed, prompting a shift to a more rigorous approach.
Goal Set #11
A new goal is set: re-evaluate the baseline model with a rigorous methodology, including comparison to optimal path length.
Work #12
The evaluation framework is rebuilt to be more rigorous, including adding a BFS solver.
Experiment #13
A rigorous evaluation is run on the trained model across multiple maze sizes.
Finding #14
The rigorous evaluation provides a clear generalization curve, showing success dropping from 97% to 18% as maze size increases.
Finding #15
In successful runs, the agent's path length is consistently ~1.8x the optimal path length.
Analysis #16
Failure cases from the evaluation are analyzed.
Eureka #17
A key failure mode is identified: the agent gets stuck in tight loops, failing to explore the maze.
Question #18
Is the generalization failure a problem of model capacity or a limitation of the learning algorithm/architecture?
Hypothesis #19
Hypothesis A: The LSTM's hidden state capacity is insufficient to map larger mazes.
Hypothesis #20
Hypothesis B: The vanilla LSTM architecture lacks the correct inductive bias for spatial mapping, regardless of capacity.
Goal Set #21
Two sets of experiments were prioritized: a hidden size ablation and an exploration bonus experiment.
Experiment #22
Four models were trained in parallel: three with increased hidden sizes (256, 512, 1024) and one with an exploration bonus.
Finding #23
The initial exploration bonus implementation failed, causing policy collapse where the agent prioritized novelty over reaching the goal, resulting in a 0% success rate.
Finding #24
Increasing model capacity improves generalization (from 60% to 77% on 2x mazes) but with diminishing returns, suggesting capacity is not the only limiting factor.
Pivot #25
The research focus shifted from capacity scaling to more advanced training strategies, specifically curriculum learning.
Goal Set #26
A primary curriculum learning experiment and a secondary, refined exploration bonus experiment were planned.
Experiment #27
A curriculum learning model and a refined exploration bonus model (v2) were trained in parallel.
Finding #28
The refined exploration bonus (v2), with a smaller, annealed reward, successfully trained and achieved 90% generalization on 2x-sized mazes.
Finding #29
Curriculum learning significantly improved generalization on very large mazes, achieving peak performance of 85% on 3x-sized mazes (31x31).
Work #30
A bug in the evaluation script related to PyTorch version compatibility was identified and fixed.
Work #31
Session wrap-up tasks were performed, including updating logs and project documentation.
Goal Set #32
The next research goals were set: 1) Validate that curriculum learning is superior to simply longer training, and 2) Push for reliable 3x generalization.
Hypothesis #33
A hypothesis was proposed that the progressive nature of curriculum learning, not just total training time, is the reason for its success.
Experiment #34
A control experiment was designed to test the curriculum hypothesis by training a model directly for an equivalent number of steps.
Experiment #35
An experiment was designed to scale the curriculum approach by extending it to 15x15 mazes.
Idea #36
An idea was suggested to analyze hidden state activations to understand the mechanism of curriculum learning, but it was deferred.
Experiment #37
The control experiment (4M direct training) and the scaling experiment (extended curriculum to 15x15) were launched in parallel.
Finding #38
The control experiment established that curriculum learning is genuinely more effective than direct training with an equivalent compute budget (90% vs 66% on 2x mazes).
Finding #39
The extended curriculum experiment demonstrated that the method scales, achieving 95% generalization on 2x mazes and 75% on ~2.7x mazes.
Work #40
Project documentation, including progress trackers and research context, was updated with the latest findings.
Goal Set #41
Set three new research goals: extend curriculum to 21x21, run multi-seed validation on the 15x15 model, and test 4x generalization.
Experiment #42
An evaluation of the 15x15 model on 61x61 mazes (4x generalization) was conducted.
Experiment #43
A multi-seed validation (3 new seeds) of the 15x15 curriculum and an experiment to extend the curriculum to 21x21 were launched in parallel.
Finding #44
The 15x15 model achieves a 50% success rate on 61x61 mazes, establishing a 4x generalization baseline.
Finding #45
The experiment to extend the curriculum to 21x21 failed due to catastrophic forgetting when transitioning from 15x15 mazes.
Finding #46
Multi-seed validation revealed high variance in the 15x15 curriculum's performance (84.5% ± 8.6% at 2x), invalidating the previous "reliable 2x generalization" milestone.
Pivot #47
A major reassessment of the project's status concluded that reliable generalization was not achieved and catastrophic forgetting is the key barrier.
Goal Set #48
A final experiment was designed to overcome forgetting by combining a finer-grained curriculum with a replay buffer.
Work #49
A new training script with replay buffer and finer curriculum logic was implemented.
Work #50
The new training script was debugged to resolve a CUDA error related to environment handling.
Experiment #51
The stabilization experiment was launched across three random seeds.
Finding #52
The stabilization experiment combining a finer curriculum and a replay buffer also failed, with the model still suffering from catastrophic forgetting.
Analysis #53
Analysis of the failed stabilization runs showed that while all failed, the exact failure mode varied across seeds (complete collapse vs. degradation to a low-performance state).
